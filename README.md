# A little birthday surprise for Shreya

A five-screen, mood-themed birthday gift built with Next.js, React, TypeScript, Tailwind CSS, Framer Motion, and a small canvas confetti effect.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Next.js. The birthday message lives in `components/BirthdayMessage.tsx`, and the six editable colour themes live in `lib/moods.ts`.

## Experience

1. Choose a colour mood.
2. Answer the playful birthday question.
3. See the birthday celebration.
4. Read a handwritten-style note.
5. Watch the penguin hug and restart with a new mood.
